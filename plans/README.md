# Plans

Implementation plans for Linear issues live here, one file per issue named
`<TAG>_PLAN.md` (e.g. `ENG-123_PLAN.md`).

The workflow: read the Linear issue → write the plan here → get developer
approval → do the work → branch, commit, push → open a PR to `main`. See the
"Issue workflow" section in [../CLAUDE.md](../CLAUDE.md) for the full process.
